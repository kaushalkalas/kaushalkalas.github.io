# kaushal-kalas-portfolio — design system bundle

A dark, developer-oriented single-page portfolio whose single job is to communicate an AI/ML-focused profile within the first few seconds and make the visit memorable. Near-black ink canvas, one warm amber-gold voltage, and an amber phosphor Debian-style terminal as the signature artifact. Every section wears a `$`-command eyebrow that maps 1:1 to a working terminal command — the page is the terminal's manual.

## How to use

1. Apply `user:kaushal-kalas-portfolio` as the active design system and bind the seven role tokens above. Do not add hex values outside the registered palette.
2. Ship the self-hosted `fonts/` (Unbounded, Instrument Sans, JetBrains Mono) — the declared fallback stacks are in the token table.
3. Match component shapes to `system/kit.html` (dark-first default) / `system/kit.dark.html`, and the artifact patterns in `system/artifacts/`.
4. For the light theme, use `light-theme.html` as the reference implementation (paper inversion, engine-derived tokens; amber `#F5A623` stays the primary). Amber on light is structural — button fills/borders with dark text, never link text.
5. Read `BRAND.md` for voice, do/don'ts, motion, responsive, and accessibility rules before writing copy.
